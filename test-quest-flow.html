🏰 Test Campaign Quest Flow

Quest Overview

Objective: Test the 3-step delivery quest

  1. Town Square → Get message scroll from merchant
  2. Castle Gate → Deliver scroll to guard
  3. Town Square → Complete quest and get reward

Test Steps

✅ Expected Behavior:

  • Visit town-square (200, 200) → Get "message_scroll" item
  • Visit castle-gate (172, 884) → Remove "message_scroll" item
  • Return to town-square → Get 5 wealth + 1 reputation reward

🎮 Manual Test Instructions:

  1. Start game and move to town-square (red circle at 200, 200)
  2. Accept the quest from merchant → Should receive "message_scroll"
  3. Move to castle-gate (red circle at 172, 884)
  4. Deliver scroll to guard → "message_scroll" should be removed
  5. Return to town-square → Should get completion dialog and reward

Debug Information

Check browser console for:

  • Inventory updates: INVENTORY_UPDATE events
  • Story triggering: TRIGGER_ENCOUNTER events
  • Hotspot detection: Player entered hotspot messages

Hotspot Locations:

town-square:    x=200, y=200, radius=60
castle-gate:    x=172, y=884, radius=40  
forest-entrance: x=800, y=150, radius=35

Inventory Functions Test

These external functions should work in Ink stories:

  • addItem("message_scroll", 1) - Adds item to inventory
  • removeItem("message_scroll", 1) - Removes item from inventory
  • hasItem("message_scroll") - Checks if player has item
  • getItemCount("message_scroll") - Returns item quantity
