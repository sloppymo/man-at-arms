## 🎯 Quest System Features

The game includes a complete 3-step quest system:

1. **Town Square**: Talk to merchant, get message scroll
2. **Castle Gate**: Deliver message scroll to guard  
3. **Return**: Complete quest for reward

## 🔧 Technical Implementation

- **Inventory Management**: Add/remove items
- **Quest Tracking**: Stage-based progress
- **Hotspot System**: Interactive locations
- **Phaser Integration**: Map and character movement
- **Ink.js Integration**: Narrative dialog system
