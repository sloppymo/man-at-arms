# Merchant Character Portrait

This directory contains portraits for the merchant character encountered in the overworld.

## Portrait Files Needed:
- neutral.png - Default merchant expression
- smile.png - Friendly/happy expression
- worried.png - Concerned/nervous expression
- scared.png - Frightened expression

## Usage in Yarn Files:
Use `<<setCharacter merchant>>` to display the merchant portrait during dialog encounters.

## Character Description:
A portly merchant with waxed mustache and fine velvet clothes. Traveling salesman who deals in various goods including food, wine, and luxury items.
